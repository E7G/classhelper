# sherpa-onnx Android runtime

The build automatically downloads the **official sherpa-onnx v1.13.5 AAR** and verifies:

`SHA-256 6419cd8bc983e0c4fab06067f0fe0313fdc0f7103818ac1e7a08d50787b7a82b`

If your build network cannot reach GitHub/SourceForge, place the official file here manually as:

`sherpa-onnx-1.13.5.aar`

The AAR is intentionally kept at v1.13.5 because this project uses the current Kotlin SenseVoice, OfflineRecognizer and Silero VAD APIs.
